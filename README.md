# Game Knights

Browser party games (He Said She Said, Answer Is, Word Fight) built with React,
Ant Design and the Firebase Realtime Database and Gemini.

## Requirements

- Node.js `^20.19.0 || >=22.12.0` (required by Vite 8)
- `VITE_APPCHECK_SITE_KEY` (see `.env.example`) for the AI story suggestions.
  Everything else runs without it.
